# Baseline Benchmarks

This directory contains baseline performance benchmarks for the iara-engine before optimizations.

## Running Benchmarks

To run the complete baseline benchmark suite:

```bash
cd ~/projects/LLM/llm-lab && cargo bench --bench baseline --features rocm
```

Or with OpenCL:

```bash
cd ~/projects/LLM/llm-lab && cargo bench --bench baseline --features opencl
```

For CPU-only benchmarks (no GPU required):

```bash
cd ~/projects/LLM/llm-lab && cargo bench --bench baseline
```

## What is Measured

The baseline benchmark suite measures performance across several dimensions:

### CPU Benchmarks (Always Available)
- **Tokenizer operations** — Text tokenization throughput on sample text (1KB)
- **JSON parsing** — Parsing small JSON objects (model config)
- **Vector operations** — Dot products on 4096-dimensional vectors

### GPU Kernel Microbenchmarks (Requires GPU Backend)
- **RMSNorm** — Normalization on 4096-dim vectors (1000 iterations)
- **Softmax** — Row-wise softmax on 32x512 matrices
- **RoPE (Rotary Position Embeddings)** — 32 attention heads, 128 head_dim
- **SiLU activation** — SiLU * mul on intermediate MLP size (4096 x 11008)

### GPU GEMM Benchmarks
- **Square GEMM (BF16)** — 4096x4096 matrix multiplication
- **MLP projection (1 token)** — 1x4096 x 4096x11008 projection
- **Attention projection (1 token)** — 1x4096 x 4096x4096 projection

### GPU Memory Benchmarks
- **Upload (8M BF16)** — Throughput uploading 8M parameters to GPU
- **Download (4096 F32)** — Throughput downloading 4096 floats from GPU
- **Memory info** — Query GPU memory utilization

## Output

Results are saved to `benchmarks/baseline_results.json` after each run.

The HTML report is generated by Criterion and located in `target/criterion/report/`.

## Hardware

This baseline was measured on:
- **GPU**: AMD Radeon RX 6750 XT
- **Driver**: ROCm with HSA_OVERRIDE_GFX_VERSION=10.3.0
- **Rust Edition**: 2021

## Next Steps

After establishing this baseline, optimizations should be measured against these results to quantify improvements.
