OBJECTIVE
================================================================================

Build a deep inference tracer that captures the FULL path a token takes
through the model during forward pass, with per-layer telemetry including:

✓ hidden_norm: L2 norm of hidden state entering the layer
✓ attn_entropy: entropy of attention scores (focused vs diffuse)
✓ attn_top_positions: which positions got highest attention (top-5)
✓ mlp_activation_rate: % of MLP neurons that survived SiLU gating
✓ mlp_top_neurons: indices of top-10 most activated MLP neurons
✓ residual_delta: L2 norm of (output - input), measuring layer change
✓ phase_coherence: Kuramoto order parameter of hidden state

Plus final output:
✓ logit_entropy: entropy of logit distribution
✓ top_tokens: top-10 token candidates with probabilities
✓ confidence: probability of chosen token

================================================================================
METRICS INTERPRETATION GUIDE
================================================================================

hidden_norm [0-100]:
  0-10:    Quiet input
  10-30:   Normal range
  30-100:  Very active

attn_entropy [0, ln(seq_len)]:
  0-1:     Highly focused
  1-3:     Moderate focus
  3+:      Diffuse attention
  NOTE: max = ln(seq_len) = 4.6 for seq_len=100

mlp_activation_rate [0-100%]:
  0-20%:   Very sparse
  40-60%:  Typical
  80-100%: Dense

residual_delta [0-100]:
  0-2:     Minimal change
  5-15:    Significant change
  >30:     Major (unusual)

phase_coherence [0-1]:
  0-0.3:   Random/chaotic
  0.3-0.7: Partial alignment
  0.7-1.0: Strong sync

logit_entropy [0, ln(vocab_size)]:
  0-2:     Very confident
  3-5:     Moderate confidence
  5+:      Uncertain

confidence [0-1]:
  0.9-1.0: Very confident
  0.5-0.9: Moderately confident
  0-0.2:   Very uncertain

================================================================================
KEY DESIGN DECISIONS
================================================================================

1. Single Token Only (n=1)
   - Simplifies sequence logic
   - Avoids batch complexity in tracing
   - Matches natural use case (token-at-a-time generation)

2. Explicit API Endpoint
   - Separate from normal generation
   - Users opt-in to slow telemetry collection
   - Clear in API design intent

3. Download Per-Layer
   - Granular telemetry collection
   - High fidelity results
   - Manageable memory footprint (~48 MB total)

4. Top-K for Neurons
   - Avoid massive JSON (10-100K neurons per layer)
   - Still get high-impact features
   - Reasonable balance of detail vs. performance

5. Entropy Over Max Activation
   - Better measure of model uncertainty
   - Applies to both attention and logits
   - More meaningful for analysis
