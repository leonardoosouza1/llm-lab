# 🏛️ IARA v3: A Software House Autônoma (Blueprint)

Este documento define a arquitetura para um sistema de desenvolvimento auto-dirigido, operando em loops infinitos de refinamento até a perfeição técnica.

## 1. O Cérebro Estratégico (Visão de Cima)

### 🗺️ O Grafo de Conhecimento do Projeto
Ao invés de prompts, usamos um **Grafo de Dependências Vivo**.
- **Nós:** Arquivos, Contratos de API, Componentes de UI, Regras de Negócio.
- **Arestas:** "Depende de", "Impacta", "Consome".

### 🔎 O CTA (Chief Technical Architect)
- **Função:** Analisa o impacto global de cada mudança.
- **Garante que:** Uma alteração no DB não quebre o Frontend, antes mesmo do código ser escrito.

## 2. A Operação Tática (Olhar de Dentro)

### 🔪 Decompositor de Micro-Tarefas (TTD)
O segredo contra a alucinação é a **Granularidade Extrema**.
- **Ação:** Nenhuma tarefa pode ter mais de 30 linhas de lógica.
- **Abordagem:** Quebra um épico (ex: "Sistema de Login") em 20 micro-tarefas paralelas (CSS do Botão, Schema da Tabela, Hash de Senha, etc).

### 🤖 Fábrica Paralela (Agents)
- Agentes trabalham em "vácuos" controlados com **Injeção de Contexto Estrita**.
- Eles recebem apenas o necessário para a micro-tarefa, eliminando ruído e alucinação.

---

## 3. O Loop Infinito (Perpetual Feedback)

O sistema roda o ciclo **RED-GREEN-REFACTOR-AUDIT** sem intervenção humana:

1.  **PLAN:** Decomposição em Micro-Tasks.
2.  **EXECUTE:** Agentes especialistas implementam em paralelo.
3.  **TEST:** Runner executa linters, testes unitários e E2E.
4.  **AUDIT:** O `@strategic-handler` revisa a segurança e a UX pós-teste.
5.  **FIX:** Se houver falha (Lint, Erro, UI Bug), o sistema re-alimenta o erro no loop 1.

---

## 🛡️ Os Pilares de Qualidade (Definição de "Entregue")

| Portal | Agente Responsável | Critério de Passagem |
| :--- | :--- | :--- |
| **Logic Gate** | `@test-engineer` | 100% Cobertura de Testes Unitários |
| **UX Gate** | `@design-engineer` | Compliance total com Design Tokens |
| **Security Gate** | `@security-auditor` | Zero vulnerabilidades críticas (Linter/Scanner) |
| **Architect Gate** | `@strategic-handler` | Código segue os padrões da `@clean-code` |
